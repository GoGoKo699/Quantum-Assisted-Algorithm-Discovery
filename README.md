# Quantum-Assisted Algorithm Discovery — exploration phase 2

**Target: PRX Quantum. Manuscript: on hold.**

Can circuit-model quantum computation reveal a simple, consequential way to discover a reusable classical method? This branch reopens exploration from the mechanism rather than extending the current extraction machinery. There is no submission timetable.

Read [the phase-2 charter](exploration/phase_2/CHARTER.md), [the opening research question](exploration/phase_2/OPENING_NOTE.md), and [the current work order](work_orders/CURRENT.md).

The leading question is whether quantum processing can expose a compact structural relation from which a useful classical shortcut follows, rather than merely test candidates faster. This is an investigation, not an established algorithm or advantage. Existing quantum primitives and polynomial improvements are allowed when their complete consequence is substantial.
