## New evidence and decision

The published zero/one-helper dependency-search core for a known 55-addition routine can be replaced by monotone target closure. In the explicit unlimited-storage gate-count model, a `d+k`-gate circuit can be found by choosing at most `k` non-target helper expressions, with polynomial deterministic target propagation. The one-helper reference is classically easy. A precise 398-state radius-two integer-ternary neighborhood is also ruled out from a local 54-addition goal; do not search it quantumly or label that exclusion global hardness.

Pause further compilation of the staged guided-graph coin until the workload earns it. The current candidate is a binary helper-choice backtracking tree. Its generic quantum theory is prior work. Neither the normal form's novelty nor a complete quantum implementation has been established.

## Next substantive work

1. Select a non-calibration, independently needed exact arithmetic map or kernel for which an improved classical circuit is not already supplied. Fix arithmetic domain, free operations, execution metric, and whether storage/latency constraints invalidate the normal form. A threshold below the historical 55 reference is not automatically globally novel; audit current records including basis-conversion costs before choosing it.
2. Run a serious native classical synthesis baseline appropriate to that map. Retain target closure, common-subexpression elimination, learned or greedy guidance, memoization, symmetry, SAT and parallelism as allowed competitors. The extracted exact dependency core is a useful calibration, not the strongest solver on all tasks.
3. Determine the actual helper budget, pruned tree, and equivalence merging. Fixed `k` already gives a classical polynomial bound (with exponent depending on `k`). Do not create difficulty by disabling state merging or choosing poor branching. Quantum tree counts include binary labels, prefixes, invalid leaves, and all deterministic node work.
4. Only after the workload survives these checks, compile reversible replay/closure and parent/child predicates, account for integer precision, memory, search repetitions and independent output verification, and compare total cost to obtain a genuinely better routine.

The deliverable is a useful workload and matched classical/quantum resource assessment, or a substantive reason to change the candidate. Do not substitute larger raw horizons, rediscovery of an available circuit, another finite-neighborhood expansion, or an isolated oracle count.
