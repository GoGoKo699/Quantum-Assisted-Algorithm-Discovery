# Current research task

Repository initialization is complete once the tested tree is committed and read back. Preserve the root MIT license and provenance. Start with README.md, STATUS.md, and docs/current-design.md. Run `python verify.py` before modifying the implementation.

## Objective

Useful circuit-model quantum advantage in discovering a reusable classical method. Do not narrow the objective to matrix multiplication, tensor rank, QML, or hardware access. The current candidate is staged guided exploration with classical algebraic progress; residual/error-correction approaches are not the chosen direction.

## Next substantive work

Select one independently valuable finite synthesis workload whose desired improvement is not already supplied by a reference or input. Specify coefficient domain, arithmetic schedule and practical success criterion, not only rank. Inspect and reproduce a serious published classical implementation before treating the current independent O(r^2) list enumerator as an opponent.

For a matched starting scheme, determine the marked set and reachable component. Account for the full legal-neighbor coin, reversible address update, marker, initialization, precision and inter-stage classical computation. Establish the search parameter required by the applicable theorem. Compare the cost to obtain the final useful routine, not just one reduction; allow classical preprocessing, expansions, adaptive learning, restarts, symmetry and parallelism.

The next deliverable is a concrete workload-and-baseline assessment plus either a justified full-search model or an explicit reason to change the mechanism. Do not replace it with another raw-walk horizon increase, an isolated gate-count optimization, or a known-identity rediscovery.

## Reporting rules

Distinguish derived identities, exact finite checks, benchmark observations, compiled logical resources, physical resources and conjectures. The old 904-qubit raw-search layout does not price the guided design. No samples with zero success establish global impossibility. Generic directed-edge addressing and Gaussian elimination are not novel contributions. A repository and reproducibility checks are infrastructure, not evidence of advantage.
