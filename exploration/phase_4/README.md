## Evidence, not hardware certification

[Readout controls](../../experiments/task_matched_readout_v1/),
[graph-contract controls](../../experiments/implicit_graph_contract_v1/), and
[short-seed controls](../../experiments/short_seed_sparsification_v1/) remain at
their original paths with unchanged reports. They check specified mathematics;
they do not run a quantum sparsifier or establish circuit-level memory costs.
[Reproduction guide](../../handover/REPRODUCING.md).

A shorter sampling seed does not make coordinate, spanner, resistance, or search
tables free to query. Parking Note 04 is not a retraction. A future eligible graph
construction would need a useful purpose and complete ordinary-circuit costs;
a forced QROM retrofit or memory-device program is not selected here.

The singular repository filename in Note 03 is canonical. Same-numbered local
03/04 checkpoint payloads are not interchangeable with repository files; see
[the provenance distinction](../../handover/ALTERNATE_CHECKPOINTS.md).
No scientific notes, code, reports, or earlier closeouts are rewritten by this
maintenance. No new phase, manuscript, repository, or spin-off is started.
